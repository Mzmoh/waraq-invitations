# Animated Invitations Studio — Reference Bundle

1. افتح ملف `CODEX_MASTER_PROMPT_AR.md` وانسخ محتواه إلى Codex.
2. أنشئ مشروعًا مستقلًا لهذا الموقع أو افتح مجلد مشروع الدعوات الجديد.
3. انسخ مجلد `references/videos/` داخل المشروع.
4. أرسل البرومبت إلى Codex، واطلب منه قراءة الـSkills المتاحة، وتحليل الفيديوهات فعليًا، ثم التنفيذ.

الملفات الأربعة للمرجعية البصرية فقط. لا تنسخ شعارات أو علامات تجارية أو محتوى محميًا.
