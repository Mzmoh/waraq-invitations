## الربط والعزل

- قاعدة Supabase جديدة مستقلة `dkizrskorelovjenqhup` في مؤسسة My Love، بكلفة إنشاء مقتبسة **$0 شهريًا**. بدأت بـ80 قالبًا و8 فئات، دون حسابات أو دعوات من الموقع الحالي. البيانات المضافة أثناء الفحص صناعية فقط.
- اتصال PostgreSQL بدور تشغيل مخصص لا يملك superuser أو BYPASSRLS، مع التحقق من شهادة TLS واسم المضيف؛ لا تعطيل للتحقق. كل جداول التطبيق الـ17 عليها RLS، وحاوية الصور والصوت خاصة. فحص security advisors بلا ملاحظات.
- بيانات الاتصال مخزنة في متغيرات Vercel الخادمية السرية، ولا توجد في Git أو public أو التقارير. لم تُستخرج بيانات اتصال المشروع الحالي أو تُنسخ بياناته.
- المعاينة متاحة دون حساب Vercel تنفيذًا لطلب الرابط العام؛ صلاحيات التطبيق وPIN وحماية الصور تبقى مفعلة. عُطّل شريط تعليقات Vercel في **المشروع الجديد وحده** لأنه كان يحقن نصًا خارجيًا تمنعه CSP؛ لم نوسّع سياسة الأمان.
- عيّنت Vercel أول بناء تلقائيًا إلى production للمشروع **الجديد** رغم عدم استعمال `--prod`. أُزيل ذلك البناء؛ الرابط المسلم يشير إلى بناء Preview صريح. لم تُربط به نطاقات الموقع الحالي.

## إصلاحات كشفتها الاستضافة

أظهرت مراجعة فيديو الموبايل إطار الدعوة فارغًا لعدة إطارات أثناء انتظار `invitation.js`. نُقل استيراد العارض قبل استبدال الغلاف الحي؛ أُعيد إنتاج الفشل بالكود السابق، ونجح الاختبار بعد الإصلاح مع تأخير الوحدة **900ms** محليًا وعلى المعاينة.

كما ظهر إطار أبيض في تمديد لقطة SVG عبر انتقال Chrome. تحت 600px تُستعمل حركة فعلية للبطاقة الحية مع تلاشي الغلاف عند جاهزية الدعوة؛ يبقى الانتقال المشترك على سطح المكتب. قورنت 25 لقطة متتابعة من آخر 2.5 ثانية من الفيديو، بفاصل 0.1 ثانية: [قبل](before-cold-renderer-contact.png)، [بعد](mobile-transition-contact.png). لا فجوة أو إطار أبيض في هذه العينة النهائية. هذا تحقق على بيئة الاختبار المحددة، وليس ضمانًا لكل GPU.

| الفحص | النتيجة والدليل |
|---|---|
| HTTP والربط الحقيقي | الصفحة و`/api/health` و`/api/catalog` تستجيب 200، وAPI يحمل no-store؛ الاتصال ليس واجهة وهمية |
| Desktop وMobile وRTL | الصفحات الرئيسية والمحرر والقوالب ولوحة التحكم عند 1440 و390 على Chrome وFirefox وWebKit؛ 11 مجموعة ناجحة، تشمل Back/Forward واستعادة التمرير؛ [النتائج](cross-browser.json) |
| الوصولية الآلية | صفر مخالفات axe في 8 فحوص Chrome للصفحات الأربع والمقاسين، WCAG 2 A/AA و2.1 A/AA؛ ليست مراجعة قارئ شاشة شاملة |
| الحركة الحقيقية | الدخولية، إطارات WebGL المتقدمة، التمرير، والبطاقة على Desktop وMobile؛ [النتائج](motion-results.json)، [Desktop](motion-desktop.webm)، [Mobile](motion-mobile.webm) |
| WebGL والفشل | MeshPhysicalMaterial حقيقي، توقف مع تغيير المقاس، فقد سياق فعلي عبر WEBGL_lose_context، CSS fallback عند غياب WebGL، وReduced Motion دون تحميل Three؛ الصفحة وروابطها تبقى قابلة للاستعمال |
| القوالب | فتح القوالب الثمانين الفريدة على 390px، تخطي الدخولية، ظهور تفاصيل الدعوة وفك الخطوط، دون تمرير أفقي؛ المعرّفات كلها في motion-results.json |
| الحساب والوظائف | تسجيل حساب جديد عبر UI نجح في الجولة الأولى؛ [النتيجة](registration-results.json). بعد بلوغ حد التسجيل الطبيعي من تكرار فحوص التخطيط، استُعمل تسجيل الدخول بحسابات صناعية موجودة؛ لم تُعدّل حدود Auth |
| رحلة الدعوة | تسجيل دخول، إنشاء، PNG وWAV فعليان، نشر PIN، تعديل وإعادة نشر، إعادة فتح، رفض الوصول للصورة قبل PIN، فتحها وتشغيل الصوت بعده، RSVP محفوظ، ومنع القراءة والكتابة بين مالكين؛ [النتيجة](lifecycle-results.json)، [الفيديو](lifecycle.webm) |
