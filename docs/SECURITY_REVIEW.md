# مراجعة الوصول والبيانات

يعتمد الخادم جلسات عشوائية تُحفظ تجزئتها في قاعدة البيانات. كلمات المرور مشتقة باستخدام scrypt وملح عشوائي مستقل. ملفات الارتباط HttpOnly وSameSite=Lax وتكتسب Secure في الإنتاج. كلمات مرور التهيئة الإدارية تُقرأ من بيئة التشغيل.

تتحقق مسارات المالك من جلسة المستخدم وملكية الدعوة على الخادم. إعدادات المسؤول محمية بدور إداري، ولا يستطيع التسجيل العادي إنشاء هذا الدور. SQL يستخدم معاملات مربوطة. تُرفض الطلبات ذات Origin خارجي أو إشارة cross-site، وتُقيَّد معدلات المصادقة والنشر والرفع وRSVP ومحاولات الرمز.

الضيف يستطيع قراءة الدعوة المنشورة الفعالة فقط. الردود وأسماء الضيوف متاحة للمالك. لا تتضمن استجابة الضيف رقم المالك أو تجزئة PIN أو بيانات الجلسة. يُحفظ PIN كتوقيع HMAC، وتُبطل صلاحيته عند تغيير الرمز. تحفظ صفحة الدعوة الخاصة بيانات Open Graph عامة، وترسل الدعوات noindex.

الصور تُعاد معالجتها في المتصفح إلى JPEG مضغوط مع إزالة بيانات الملف الأصلية. يتحقق الخادم من صيغ الصور النقطية وأبعادها وحد الحجم. SVG المرفوع مرفوض. الصور المضمنة تتحول إلى سجلات أصول خاصة، وتُربط بالدعوة في معاملة واحدة. تمنع triggers إسناد أصل لمستخدم آخر، وتحدد حصة الصور وعدد الدعوات. تُحذف الأصول المدارة التي تُزال من آخر دعوة تستخدمها. ينفذ خادم الصور صلاحيات الدعوة والرمز أيضًا.

تستخدم التعديلات نسخة زمنية تتزايد رتيبًا وتحديثًا مشروطًا. يرفض الخادم التعديل المتزامن القديم. تحفظ معاملات الصور والدعوة والأرشيف اتساق الحالة.

تطبق الصفحة Content Security Policy وX-Content-Type-Options وReferrer-Policy. تُرمَّز نصوص الدعوات قبل إدراجها في HTML وتُقيَّد روابط الخرائط وRSVP. لا تتضمن حزمة المتصفح أسرار الخادم.

اختبارات الضوابط مسجلة في TEST_RESULTS.md. اعتماد التشغيل العام يتطلب إدارة النسخ الاحتياطية وحساب المسؤول ومراقبة السعة على المضيف. المصادقة بالبريد وكلمة المرور متاحة. تحقق البريد واسترجاع كلمة المرور وGoogle OAuth يتطلبان تكامل خدمات إضافيًا. تقييم أداء أجهزة الهاتف الفعلية ما زال مفتوحًا.
