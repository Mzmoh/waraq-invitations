# وَرَق

المصدر المعتمد هو CODEX_MASTER_PROMPT_AR.md. استُخرج مع أربعة فيديوهات من حزمة البداية المرفقة وتطابق محتوى نسخته الخارجية عبر SHA-256. بدأ المشروع في مجلد مستقل، ولم يكن المجلد الأب مستودع Git.

الرحلة الأساسية تبدأ باختيار مناسبة ثم معاينة قالب متحرك. يستطيع الزائر تجربة المحرر قبل تسجيل الدخول. النشر يحفظ دعوة في قاعدة البيانات ويخصص مسارًا للضيوف. الردود تظهر للمالك في لوحة دعواته.

اعتمد التنفيذ خادم Node.js وSQLite محليًا ووحدات JavaScript للمتصفح. اختير هذا المسار لاختبار دورة الحفظ والنشر كاملة في البيئة المتاحة بكل وظائف الخادم. اقتراح Next.js وSupabase في المواصفات كان مشروطًا بالإمكانات. أضيف Worker مستقل مع D1 يستخدم نفس منطق API لتجهيز نشر دائم. يمكن أيضًا استضافة خادم Node.js مع تخزين دائم وHTTPS.

أُجري استعلام نظام تصميم UI UX Pro Max لفئة استوديو دعوات زفاف فاخر، واستُخدمت توصيات سرد الحركة وإبقاء تجربة الفتح مفهومة تحت تقليل الحركة وفصل تصميم التحرير عن تصميم الدعوة. تولدت صورة الخلفية التحريرية للصفحة الرئيسية من Image Gen ثم ضُغطت إلى WebP.
