# مراحل تنفيذ وَرَق

تُسجل نتيجة كل اختبار في TEST_RESULTS.md. وتوثّق REFERENCE_ANALYSIS.md المراجعة المرئية للمقاطع الأربعة.

- P0 — استخراج المواصفات والمراجع وفحص نقطة البداية.
- P1 — بناء هوية وَرَق، الرئيسية، صفحات الفئات، البحث، الفلترة والتنقل بين العربية والإنجليزية.
- P2 — ربط التحرير والمسودات والمصادقة والنشر بقاعدة بيانات.
- P3 — مشاهد الافتتاح والكشف، إعداد الحركة، الأقسام والعداد الحي.
- P4 — سجل القوالب حسب المناسبة والأغلفة والمعاينة.
- P5 — لوحة المالك، ردود الضيوف، الخصوصية والمشاركة.
- P6 — اختبارات البناء والرحلات والتحقق من ضوابط الخادم.
